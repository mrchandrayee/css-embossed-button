A responsive recreation of the uploaded 22.6-second screen recording.

## Five effects shown in the video
1. **Magnetic** — pointer position moves the button slightly and controls a soft radial highlight.
2. **3D Tilt** — pointer position updates `--rx` and `--ry` CSS variables to rotate the button in perspective.
3. **Pulse** — subtle breathing scale plus expanding/fading outline rings.
4. **Shadow Wave** — a pointer-tracked radial highlight glides across the neumorphic surface.
5. **Press Me** — inset shadow while pressed and a spring-style bounce animation on click.

## Run
Extract the ZIP and open `index.html` in a modern browser. No dependencies or build process required.

## Source fidelity
The five names and main visible CSS declarations are based on the screen recording. The Magnetic and 3D Tilt snippets were readable in part; Pulse, Shadow Wave and Press Me declarations/keyframe values were transcribed where visible. Supporting markup, base styles, pointer-event JavaScript and unreadable/missing code have been reconstructed to make each effect functional. This is not the original source repository or a byte-for-byte extraction.
